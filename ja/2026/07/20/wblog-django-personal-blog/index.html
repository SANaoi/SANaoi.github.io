はじめに

大学一年生の頃、プログラミングを学び始めたばかりのときから、自分だけの個人ブログを作ってみたいと思っていました。その思いをきっかけに、Django を使った個人プロジェクトを作りました。

コンピュータを学び始めたばかりの自分にとって、このプロジェクトの開発から得たものはとても多かったです。単なる Web ページ制作の練習ではなく、実践を通して多くのコンピュータの基礎知識やエンジニアリングの考え方に触れることができました。たとえば、バックエンドフレームワークがどのようにコードを整理するのか、データベースのモデルをどう設計するのか、ユーザーログインの状態をどう管理するのか、テンプレートでページをどう描画するのか、そして一つのプロジェクトをどのように分かりやすいモジュールへ分割していくのか、といったことです。

この経験は今でも強く印象に残っているので、ここに記録しておきます。当時の学習過程を振り返るためでもあり、この Django プロジェクトを一つの区切りとしてまとめるためでもあります。

プロジェクト概要

wblog は Django で開発した個人ブログシステムです。デフォルトでは SQLite データベースを使用し、ページは主に Django テンプレートで描画しています。フロントエンドの見た目には Bootstrap とローカルの静的ファイルを使っています。

プロジェクトは主に次のモジュールで構成されています。

  • article：記事モジュール
  • comment：コメントモジュール
  • notice：通知モジュール
  • userprofile：ユーザーモジュール
  • private_info：個人情報管理モジュール

それぞれのモジュールは比較的独立しており、各モジュールが自分のモデル、ビュー、ルーティングを担当しています。全体の構造は分かりやすく、後から機能を拡張しやすい形になっています。

主な機能

記事管理

記事モジュールは、このプロジェクトの中心となる機能です。

ユーザーは記事を作成、編集、削除できます。各記事にはタイトル、本文、作者、作成日時、更新日時、閲覧数、タグ、カテゴリ、カバー画像などの情報があります。

記事本文は Markdown の描画に対応しているため、見出し、リスト、コードブロック、表などを含む内容を比較的簡単に書くことができます。また、閲覧数の記録やいいね機能も追加しており、記事を表示するだけでなく、簡単なインタラクションもできるようにしています。

カテゴリとタグ

記事を整理しやすくするために、wblog ではカテゴリとタグ機能を用意しています。

カテゴリは、技術メモ、生活記録、学習まとめなど、比較的固定された分類に向いています。

タグはより柔軟に使えます。たとえば Django、Python、フロントエンド、データベースなど、複数のキーワードを記事に付けることができます。カテゴリとタグを使うことで、記事をより探しやすく、整理しやすくできます。

コメントと返信

wblog には記事へのコメント機能があります。

コメントモジュールでは django-mptt を使ってコメントツリーを管理しています。そのため、通常のコメントだけでなく、既存のコメントへの返信もできます。この構造は、単にコメントを平らに並べる方式よりも、実際のブログでのやり取りに近い形です。

コメント本文には CKEditor のリッチテキストエディタを使っており、より表現力のある内容を入力できます。

サイト内通知

ユーザーがコメントや返信を受け取ると、システムはサイト内通知を生成します。

通知モジュールは django-notifications-hq をもとに実装しています。未読通知を確認したり、通知を既読にしたりできます。この機能によって、ブログは単に静的に記事を表示するだけでなく、ある程度の交流体験を持つようになっています。

ユーザーシステム

このプロジェクトでは Django 標準の認証システムを使い、ユーザー登録、ログイン、ログアウト、プロフィール編集を実装しています。

ユーザープロフィールでは、電話番号、アバター、自己紹介を管理できます。機能としては複雑ではありませんが、ブログシステムでよく使われる基本的なユーザー機能は一通り含まれています。

これは若葉 睦です。とてもかわいいです。

個人情報管理

ブログ機能に加えて、wblog には private_info という個人データを管理するためのモジュールもあります。

現在、このモジュールには次の機能があります。

  • 連絡先管理
  • メモ管理
  • 家計記録管理

連絡先機能では、名前、連絡先、勤務先、都市、メモ、アバターを記録できます。

メモ機能では、イベント、時間、場所を記録できます。

家計記録機能では、収入、支出項目、支出金額、支出日時を記録し、日付ごとに整理して表示できます。

このモジュールによって、wblog は単なるブログシステムではなく、簡単な個人生活情報管理ツールのような役割も持つようになっています。

技術的な実装

wblog は Django をバックエンドフレームワークとして使用し、全体としては伝統的な MVT アーキテクチャを採用しています。

主に使っている技術は次の通りです。

データベースモデルは、主に記事、コメント、ユーザープロフィール、個人情報を中心に設計されています。Django ORM がデータの読み書きを担当し、Django テンプレートがページの表示を担当します。

このプロジェクトでは、複雑なフロントエンドとバックエンドの分離構成は採用していません。そのため、開発や理解のコストは比較的低く、Django の学習プロジェクトや個人練習用プロジェクトとして扱いやすい構成になっています。

このプロジェクトで得たもの

wblog を通して、Django 開発でよく使われる多くの内容を練習できました。

  • モデル設計
  • フォーム処理
  • ファイルアップロード
  • ユーザー認証
  • ログイン権限管理
  • ページネーション
  • 検索
  • Markdown 描画
  • コメントツリー構造
  • サイト内通知
  • テンプレートの再利用
  • 静的ファイル管理

単一機能だけの小さな Demo と比べると、wblog はより完整な小型 Web アプリケーションに近い存在です。複数のよく使われる機能を一つに組み合わせることで、Django プロジェクト開発の全体的な流れをより実感できました。

まとめ

wblog は Django を使って作った個人ブログ兼情報管理システムです。記事を書くためにも使えますし、連絡先、メモ、家計記録などの個人情報を管理することもできます。

機能面では、ブログプロジェクトでよく見られる記事、コメント、ユーザー、通知モジュールを含んでいます。学習面では、Django 開発でよく使う多くの知識点を一つにつなげる経験になりました。

まだ改善できる部分は多くありますが、個人用 Web アプリケーションとしての基本的な形はすでに備えています。自分にとって wblog は単なるブログシステムではなく、Django の基礎力を一つにまとめるための実践でもありました。
