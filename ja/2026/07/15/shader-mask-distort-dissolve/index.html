目標

グラフィックス表現では、現実世界の見た目を再現するだけでなく、エフェクトを実現したり、画面をより魅力的に見せたりすることも多くあります。マスク、歪み、ディゾルブなどは、ゲーム内でもよく使われる代表的なエフェクトです。

この記事では、URP HLSL Shader を使って「テクスチャ歪みディゾルブ」エフェクトを実装します。主に次の 3 つの要素で構成されています。

  • マスク：テクスチャの表示範囲を制御する。
  • 歪み：ノイズでメインテクスチャの UV を揺らす。
  • ディゾルブ：グレースケール画像としきい値でピクセルを表示するかどうかを制御する。

考え方

グラフィックスレンダリングへの理解が深まるほど、Shader はさまざまな派手な表現を作れる一方で、基本的な考え方は似ていると感じます。つまり、頂点の位置を制御し、テクスチャのサンプリングを制御し、最終的にピクセルが出力する色を制御するということです。

今回実装する 3 つの効果は、本質的にはピクセル段階で行われます。

マスク

マスクは、テクスチャのチャンネルをサンプリングし、その値で最終的な表示範囲を制御します。通常、0 は透明、1 は不透明、中間値は半透明を表します。

歪み

歪みは、歪みテクスチャの RG チャンネルをサンプリングして 2 次元のオフセット値を取得し、その値でメインテクスチャの UV をずらします。UV が変わるとメインテクスチャのサンプリング位置も変わるため、水面、熱気、エネルギーの揺らぎのような表現を作れます。

ディゾルブ

ディゾルブは、グレースケール値としきい値によってピクセルを表示するかどうかを決めます。グレースケール値がしきい値より大きいピクセルは残り、小さいピクセルは破棄されます。そのため、ディゾルブにはディゾルブテクスチャだけでなく、ディゾルブの進行度を制御するしきい値パラメータも必要です。

そのため、必要な主要パラメータはかなり明確です。

パラメータ 役割
_MainTex メインテクスチャ。基本色を提供する
_MaskTex マスクテクスチャ。表示範囲を制御する
_DistortTex 歪みテクスチャ。UV オフセットを制御する
_DissolveTex ディゾルブテクスチャ。グレースケールによる破棄判定の基準になる
_DissolveThreshold ディゾルブしきい値。ディゾルブの進行度を制御する
_DissolveEdge ディゾルブエッジの幅
_RampTex ディゾルブエッジの色

上記の説明から分かるように、マスク、歪み、ディゾルブは主にフラグメント段階で完成します。頂点段階では、モデル座標をクリップ空間へ変換し、フラグメント段階で必要になる UV を渡します。

実装

レンダリングステート

頂点関数とフラグメント関数を書く前に、透明系エフェクトでよく使うレンダリングステートを設定します。

Blend は、現在の色と画面上にすでにある色をどのように合成するかを制御します。透明マテリアルでは、よく次の設定を使います。

Cull は、表面、裏面、または両面のどれを描画するかを制御します。多くのエフェクト用の板ポリゴンは表裏どちらからも見える必要があるため、マテリアルパネルから切り替えられるようにしておくと便利です。

ZWrite Off は、深度書き込みを無効にする設定です。透明オブジェクトでは深度を書き込むと、あとから描画される透明オブジェクトを遮ってしまい、透明ソートや重ね合わせの結果が不自然になることがあります。

入力と出力の構造体

まず、頂点入力と頂点出力の構造体を定義します。

注意点として、ディゾルブはメインテクスチャと一致させたいので、ここでは dissolveUV を別に渡していません。あとで _DissolveTex をサンプリングするときは、歪み適用後の mainUV をそのまま使います。これにより、メインテクスチャが歪んだとき、ディゾルブのエッジも一緒に歪みます。

頂点段階

頂点関数では、主に 2 つのことを行います。頂点座標の変換と、いくつかのテクスチャ UV の計算です。

TRANSFORM_TEX は、マテリアルパネルの Tiling と Offset を適用します。そこにさらに次の値を足すことで、テクスチャを時間に合わせてスクロールさせられます。

フラグメント段階：メインテクスチャを歪ませる

フラグメント段階では、まずメインテクスチャの UV を取り出します。

歪みを有効にしている場合は、歪みテクスチャをサンプリングします。

テクスチャのサンプリング値は 0~1 ですが、UV オフセットには正負両方向が必要なので、-1~1 に変換します。

これで mainUV は歪みテクスチャによって揺らされます。その後、この UV でメインテクスチャをサンプリングします。

フラグメント段階：ディゾルブ裁剪

ディゾルブも同じ mainUV を使用します。

次に clip でピクセルを裁剪します。

clip のルールは、渡した値が 0 より小さい場合、そのピクセルを破棄するというものです。

_DissolveThreshold が 0 から 1 に増えていくと、破棄されるピクセルが増え、ディゾルブ効果になります。

フラグメント段階：マスクを適用する

最後にマスクテクスチャをサンプリングします。

効果表示

ディゾルブエッジの色

ここまでのディゾルブは clip だけを使っています。

このコードは、ピクセルを破棄するかどうかだけを決めます。つまり、ピクセルは表示されるか消えるかのどちらかなので、エッジが硬く見えます。ディゾルブをより分かりやすく見せたい場合は、裁剪しきい値に近い部分に色を加えると効果的です。

まず、2 つのパラメータを追加します。

_DissolveEdge はエッジ幅を制御し、_RampTex はエッジの色を制御します。

フラグメント段階では、clip のあとにエッジ範囲を計算します。

ここで重要なのは次の部分です。

これは、現在のピクセルがディゾルブしきい値からどれだけ離れているかを表します。0 に近いほどディゾルブエッジに近く、値が大きいほどエッジから離れています。

さらに _DissolveEdge で割ることで、エッジ範囲を指定した幅に収めます。最後に saturate で結果を 0~1 に制限します。

次に、edgeValue を使って Ramp テクスチャをサンプリングします。

エッジからの距離に基づいて Ramp テクスチャをサンプリングするため、テクスチャの U 方向だけを使い、V 方向は中央の 0.5 に固定します。

最後に、エッジ色を元の色に加算します。

ここで 1.0h - edgeValue を掛けているのは、色をディゾルブエッジ付近に集中させるためです。
