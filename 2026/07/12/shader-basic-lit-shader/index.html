目标

一般来说，3D 物体所使用的材质 Shader，都会包含几个比较基础的部分：UV 贴图、法线、光照接收，以及阴影生成。

本文的目标，就是先实现一个基础的 Lit Shader，并把它作为后续效果的起点。

包含什么

这次实现的 Shader 主要包含以下几个部分：

  • 基础颜色和贴图控制物体表面颜色
  • UV 贴图采样
  • 法线贴图增强表面细节
  • 使用Lambbert光照模型计算光照
  • 通过 ShadowCaster Pass 让物体可以生成阴影

法线贴图

普通颜色贴图只能改变表面的颜色，但不会改变光照计算时使用的方向。

法线贴图的作用，是让每个像素拥有一个额外的法线方向。这样即使模型本身没有更多面数，光照结果也能表现出凹凸细节。

需要注意的是法线贴图不是让模型真的产生凹凸，而是改变了光照计算时使用的法线方向。这里得到的 normalTS 是切线空间下的法线。它还不能直接参与世界空间光照计算，需要先进行空间转换。

TBN 空间转换

好，现在纹理采样和法线贴图的部分都已经完成。接下来是实现光线计算，但要在世界空间下进行光照计算，需要把切线空间下的法线转换到世界空间。所以我们需要 TBN 矩阵。

模型顶点中通常会包含法线和切线信息。通过 Unity 提供的 GetVertexNormalInputs，可以得到世界空间下的 Normal、Tangent 和 Bitangent。分别代表法线、切线和副切线方向。切线和副切线方向是互相垂直的，并且都在表面切线平面上。法线、切线和副切线三个方向可以组成一个正交矩阵，也就是 TBN 矩阵。

这三个方向可以组成 TBN 矩阵，用来把法线贴图中的切线空间法线转换到世界空间。

光照计算

光照计算是 Shader 中最核心的部分。这里使用了 Lambert 光照模型，它是最基础的漫反射光照模型，用来模拟光线在粗糙表面的均匀散射效果。模型核心公式是：

Cdiffuse = Calbedo · Clight · max(0, N · L)

其中：

  • C_diffuse：最终计算得到的漫反射光颜色。
  • C_albedo：材质本身的颜色，也就是贴图颜色。
  • C_light：入射光的颜色和强度。
  • N：表面法线方向，通常需要是单位向量。
  • L：指向光源的方向，通常也需要是单位向量。

当表面越正对光源时，N · L 越接近 1，光照越强；当表面背对光源时，N · L 会小于 0。由于光照强度不能为负数，因此需要使用 max(0, N · L) 将结果限制在非负范围内。在 Shader 中通常使用 saturate 来实现这一点：

但在实际计算中，光照还需要考虑阴影、距离衰减和环境光等因素。因此，直接光照部分可以扩展为：

Cdirect = Calbedo · Clight · max(0, N · L) · Adistance · Ashadow

其中：

  • A_distance：距离衰减值，范围通常是 0 ~ 1，表示光照随距离变远而减弱。
  • A_shadow：阴影衰减值，范围通常是 0 ~ 1，表示当前片元是否受到阴影遮挡。
  • 当 A_shadow = 0 时，表示当前片元完全处于阴影中，直接光照被遮挡。
  • 当 A_distance = 0 时，表示当前片元距离光源过远，直接光照衰减为 0。
  • 当二者都为 1 时，表示当前片元完整受到该光源的直接光照影响。

阴影生成

除了光照计算，为了让物体更加真实，还需要让物体能够投射阴影。但如果要亲手实现阴影生成，难度会比较大。幸运的是，URP 已经帮我们实现了阴影贴图的生成和采样，我们只需要在 Shader 中声明一个 ShadowCaster Pass，就可以让物体投射阴影。具体步骤如下：

  • Tags { "LightMode" = "ShadowCaster" }：告诉 URP 这是一个阴影生成 Pass，URP 会在渲染管线中为每盏灯光单独渲染这个 Pass，并把结果写入阴影贴图。
  • ZWrite On：开启深度写入，把物体深度写入阴影贴图。
  • ZTest LEqual：使用小于等于的深度测试，保证遮挡关系正确。
  • ColorMask 0：关闭颜色输出，因为阴影贴图只关心深度，不需要写入颜色。
  • ShadowPassVertex：URP 内置的阴影顶点着色器函数。
  • ShadowPassFragment：URP 内置的阴影片元着色器函数。
  • ShadowCasterPass.hlsl：URP 提供的阴影生成实现，里面已经处理了阴影偏移、裁剪、不同光源类型阴影等细节。

需要注意的是，ShadowCaster Pass 只解决“这个物体能不能投射阴影”的问题。至于“这个物体能不能接收阴影”，则是在前面的光照 Pass 中完成的，也就是通过 GetMainLight(shadowCoord) 得到 mainLight.shadowAttenuation，再把阴影衰减乘到直接光照结果中。

小结

本节主要实现了一个基础的 Lit Shader。它已经具备了颜色贴图采样、法线贴图、基础 Lambert 光照、环境光、阴影接收以及阴影生成等功能。
这些功能能满足大部分基础材质的需求，但它仍然只是一个简化版的光照 Shader。比如，当前只使用了基础颜色贴图和法线贴图，还没有加入高光贴图、金属度贴图、粗糙度贴图、AO 贴图等更完整的材质信息。

另外，Lambert 光照模型只计算漫反射光照，没有包含高光、反射、金属度、粗糙度等效果。如果想要进一步模拟更真实的材质表现，就需要在此基础上继续实现 Blinn-Phong 或 PBR 光照模型（Physically Based Rendering，基于物理的渲染）。
