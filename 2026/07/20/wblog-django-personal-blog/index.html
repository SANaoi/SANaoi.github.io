前言

记得在大一最开始学习编程时，就想着做一个属于自己的个人博客。以此为契机，我做了一个基于 Django 的个人项目。

对一个计算机初学者来说，开发这个项目让我收获颇丰。它不只是一次简单的网页开发练习，也让我在实践中接触并理解了很多计算机基础知识和工程理念。比如后端框架如何组织代码、数据库如何设计模型、用户登录如何维护状态、模板如何渲染页面，以及一个项目应该如何逐渐拆分成清晰的模块。

这个过程给我留下了很深的印象，所以现在把它记录下来。一方面是对当时学习过程的回顾，另一方面也算是给这个阶段性的 Django 项目做一个总结。

项目简介

wblog 是一个基于 Django 开发的个人博客系统。项目默认使用 SQLite 数据库，页面主要通过 Django 模板渲染，前端样式使用 Bootstrap 和本地静态资源。

项目主要包含以下几个模块：

  • article：文章模块
  • comment：评论模块
  • notice：通知模块
  • userprofile：用户模块
  • private_info：个人信息管理模块

这些模块相对独立，每个模块负责自己的模型、视图和路由，整体结构比较清晰，也方便后续继续扩展。

核心功能

文章管理

文章模块是整个项目的核心功能。

用户可以创建、编辑和删除文章。每篇文章包含标题、正文、作者、创建时间、更新时间、浏览量、标签、分类和封面图等信息。

文章正文支持 Markdown 渲染，因此可以比较方便地编写带有标题、列表、代码块和表格的内容。项目还为文章增加了浏览量统计和点赞功能，让博客内容不仅可以展示，也能有一些简单的互动反馈。

分类与标签

为了方便整理文章，wblog 支持文章分类和标签功能。

分类适合用来做固定的内容归档，比如技术笔记、生活记录、学习总结等。

标签则更加灵活，可以给文章添加多个关键词，例如 Django、Python、前端、数据库等。通过分类和标签，可以更方便地筛选和查找文章。

评论与回复

wblog 支持文章评论功能。

评论模块使用 django-mptt 来组织评论树，因此不仅可以发表一级评论，也可以对已有评论进行回复。这种结构比普通的平铺评论更接近真实博客中的交流方式。

评论内容使用 CKEditor 富文本编辑器，可以输入更丰富的文本内容。

站内通知

当用户收到评论或回复时，系统会生成站内通知。

通知模块基于 django-notifications-hq 实现，可以查看未读通知，也可以将通知标记为已读。这个功能让博客不只是静态展示文章，也具备了一定的互动体验。

用户系统

项目使用 Django 自带的用户认证体系，实现了用户注册、登录、退出和资料编辑功能。

用户资料模块中可以维护手机号、头像和个人简介。虽然功能不算复杂，但已经覆盖了博客系统中比较常见的用户基础能力。

个人信息管理

除了博客功能，wblog 还加入了一个 private_info 模块，用来管理一些个人数据。

目前这个模块包含：

  • 联系人管理
  • 备忘录管理
  • 财务记录管理

联系人功能可以记录姓名、联系方式、工作地点、城市、备注和头像。

备忘录功能可以记录事件、时间和地点。

财务记录功能可以记录收入、支出项目、支出金额和支出时间，并按照日期进行整理展示。

这个模块让 wblog 不只是一个博客系统，也更像一个简单的个人生活信息管理工具。

技术实现

wblog 使用 Django 作为后端框架，整体采用传统的 MVT 架构。

项目没有引入复杂的前后端分离架构，因此开发和理解成本相对较低，比较适合作为 Django 学习项目和个人练习项目。

项目收获

通过 wblog 这个项目，可以练习到 Django 开发中的很多常用内容：

  • 模型设计
  • 表单处理
  • 文件上传
  • 用户认证
  • 登录权限控制
  • 分页
  • 搜索
  • Markdown 渲染
  • 评论树结构
  • 站内通知
  • 模板复用
  • 静态资源管理

相比只写单个功能的小 Demo，wblog 更像是一个完整的小型 Web 应用。它把多个常见功能组合在一起，更能体现 Django 项目开发中的整体流程。

总结

wblog 是一个基于 Django 的个人博客与信息管理系统。它既可以用来记录文章，也可以管理联系人、备忘录和财务记录等个人信息。

从功能上看，它覆盖了博客项目中常见的文章、评论、用户和通知模块；从学习角度看，它也串联起了 Django 开发中很多常用知识点。

虽然项目还有不少可以继续优化的地方，但它已经具备了一个个人 Web 应用的基本形态。对我来说，wblog 不只是一个博客系统，也是一次把 Django 基础能力整合起来的实践。
